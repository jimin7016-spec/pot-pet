# 🌱 화분 펫 (pot-pet)

화분 색은 내가 고르고, 안에서 뭐가 자랄지는 랜덤인 도트 화분을 바탕화면에서 키우는 프로그램이에요.
화분은 모니터 전체를 돌아다니고, 상태와 도감은 숨길 수 있는 스티커 메모 창으로 떠 있어요.

## 실행 방법 (Windows)

폴더 안의 **`START.bat` 을 더블클릭**하면 끝이에요. Node.js 도, 설치도 필요 없어요.
처음 한 번은 Windows 에 기본으로 들어 있는 .NET Framework 로 `native\dist\PotPet.exe` 를 몇 초 만에 만들고, 그다음부터는 바로 화분이 떠요.

- 동료에게 줄 때는 `native\dist\PotPet.exe` 파일 하나만 보내면 돼요(그림·폰트가 모두 안에 들어 있어요).
- 이미 켜져 있을 때 한 번 더 실행하면, 떠 있는 화분을 화면 아래로 불러와요.

### 예전 Electron 버전에서 바뀐 점 (2026-10)
예전에는 Electron(크롬 + Node.js)으로 돌아갔는데, C# 으로 다시 만들어서 훨씬 가벼워졌어요. 같은 PC 에서 잰 값:

| | 지금 (C#) | 예전 (Electron) |
| --- | --- | --- |
| 메모리 | 약 43MB | 약 480MB |
| CPU (12코어 기준, 가만히 있을 때) | 약 0.2% | 약 4~8% |
| 필요한 것 | 없음 | Node.js + Electron(약 100MB) 내려받기 |

1초에 30번만 계산하고 그림이 바뀐 프레임만 화면에 보내요. 투명한 곳은 Windows 가 클릭을 뒤 창으로 넘겨줘서 마우스 위치를 계속 묻지 않아도 돼요.
저장 파일은 예전과 같아서 키우던 화분·도감·아이템이 그대로 이어져요. 예전 코드는 git 첫 커밋(v0.3.0)에 남아 있어요.

## 키우는 방법

- 씨앗에서 다 자랄 때까지 **물 먹은 시간 8시간**(하루)이에요. 물은 한 번에 3시간 버텨요.
- 단계: 씨앗 → 새싹(30분) → 쑥쑥(2시간) → **정체 공개**(4시간) → 수확(8시간).
  새싹일 때는 다 비슷하고, 잎 색만 조금 달라요. 4시간 지나 모양이 잡히면 무슨 식물인지 알려줘요.
- 물이 떨어지면 죽지 않고 **시들어서** 성장만 멈춰요. 고개를 푹 숙이고 눈물이 맺혀요. 물을 주면 살아나요.
- **물을 너무 많이 줘도 시들어요.** 물이 이미 가득할 때(90% 이상) 또 주면 과습이 돼요. 성장이 절반 속도로 느려지고, **다음 성장 단계에 오르면 저절로 회복**해요. 물이 가득할 때 누르면 먼저 "한 번 더 눌러요" 하고 물어보고(4초 안에 다시 누르면 진짜로 줘요), 과습인 동안은 물이 모자라지기(25% 미만) 전까지 더 줄 수 없고, 모자라지면 다시 줄 수 있어요. 물 주기는 상태 메모의 「물 주기」 버튼이나 화분 우클릭 메뉴로 해요.
- 다 자라면 도감에 등록되고, "새 씨앗 심기"로 다음 씨앗을 뽑아요.
- 프로그램을 꺼 둔 동안에도 시간이 흐른 만큼 자라요 (최대 하루치).

### 식물 10종 + 친구 7종 (도감)

| 희귀도 | 확률 | 종류 |
| --- | --- | --- |
| 일반 | 60% | 방울토마토, 바질, 선인장, 해바라기, 상추, 민트, 흰 강아지, 햄스터 |
| 희귀 | 30% | 딸기, 라벤더, 분홍 비버, 찌오, 찌둥 |
| 레어 | 10% | 보라 바질, 황금 방울토마토 (반짝여요), 비글, 보라 친구 |

**친구 7종**도 같은 확률표에 섞여 있어요. 씨앗 → 새싹까지는 식물과 똑같이 생겨서 모르고, 쑥쑥 단계에서 맨 위에 동그란 봉오리가 맺히면 친구일지도 몰라요. 4시간에 정체가 드러나면 머리에 새싹을 단 캐릭터가 흙에서 작게 나오고, 수확할 때까지 1시간마다 몸이 커져요(수확하면 머리의 새싹에 꽃이 펴요).

## 조작

| 동작 | 결과 |
| --- | --- |
| 화분을 **누른 채 좌우로 문지르기** | 쓰다듬기. 하트가 나오고 애정이 차요. 애정이 차면 성장이 빨라져요 (식물 한 개당 최대 2시간치) |
| 화분 **Shift + 드래그** (또는 휠 클릭 드래그) | 들어서 옮기기 |
| 화분 **우클릭** | 메뉴 (물 주기, 새 씨앗, 상태/도감 메모, 화분 색, 지내는 방식, 크기, 종료) |
| 상태 메모의 **물 주기** 버튼 | 물 주기 |
| 메모 머리글 드래그 / × | 메모 옮기기 / 숨기기 |
| **Ctrl + Alt + P** | 화분과 메모 전부 숨기기 / 다시 보이기 |
| 트레이 아이콘 우클릭 | 숨기기, "화분 불러오기"(못 찾을 때), 메모 켜기/끄기, 종료 |

### 지내는 방식 (우클릭 → 지내는 방식)

- **화면 전체 돌아다니기** (기본): 모니터 어디든, 모니터가 여러 개면 모니터 사이도 넘나들어요. 가끔 커서를 따라와요.
- **작업표시줄 위 걷기**: 바닥만 걸어요. 들어서 놓으면 바닥으로 떨어져요.
- **커서 따라가기**: 커서를 계속 졸졸 따라와요.
- **가만히 있기**: 제자리에서 가끔 폴짝만 해요.

걸어 다니다가 가끔 **폴짝** 뛰어요. 그리고 **혼잣말**을 해요. "오늘도 홧팅이에요!", "물 한 잔 마셔요~" 같은 응원과 귀여운 말, 시간대별 말이 나와요. 우클릭 → **말 걸기**에서 자주(1~2분) / 가끔(2~4분, 기본) / 조용히로 바꿀 수 있어요. 문구는 `native/Game.cs` 맨 위의 `TALK_` 목록에서 마음대로 고칠 수 있어요.

그 밖에: 화분 말고 투명한 부분은 클릭이 뒤쪽 창으로 그대로 통과해요. 키보드와 마우스 입력이 5분 없으면 낮잠을 자요(zzz). 아침, 점심, 퇴근 시간에 인사해요.

## 아직 안 들어간 것

- **창 위에 앉기 / 창 뒤에 짱박기**: 체험판에서 보여드린 가짜 창이 아니라 실제 창 위치를 알아야 해서, 이 버전에는 없어요. (다음 단계에서 추가 가능)
- 찾아오는 손님(나비 등)

## 내 입맛대로 바꾸기

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 성장 시간, 물 줄어드는 속도, 확률, 식물 이름, 쓰다듬기 보너스, 아이템 | `native/Logic.cs` 맨 위 |
| 화분/식물 그림, 색깔, 새 식물 추가 | `native/Sprites.cs` |
| 걷는 속도, 점프 빈도, 따라다니는 빈도, 혼잣말 문구, 낮잠 시간 | `native/Game.cs` |
| 메모 창 모양 | `native/Notes.cs` |
| 우클릭 메뉴, 트레이, 단축키 | `native/App.cs` |

고친 뒤에는 `START.bat` 을 다시 실행하면 저절로 다시 빌드돼요(켜져 있던 화분은 먼저 종료). 규칙 검사까지 하려면:

```
powershell -ExecutionPolicy Bypass -File native\build.ps1 -Test
```

윈도우 시작 시 자동 실행은 `native\dist\PotPet.exe` 의 바로가기를 `Win + R` → `shell:startup` 폴더에 넣으면 돼요.

## 글꼴

한글 도트 폰트 **Neo둥근모** 를 exe 안에 넣어 두었어요 (SIL OFL 1.1, `native/assets/FONT-LICENSE.txt`). 인터넷 없이도 나와요.

## 저장 위치

`%APPDATA%\pot-pet\` 안의 `potpet-save.json` (게임), `potpet-ui.json` (메모 창 위치). 지우면 처음부터 다시 시작해요.

## 문제 해결

- **화분이 안 보여요**: 트레이 아이콘 우클릭 → "화분 불러오기", 또는 Ctrl+Alt+P 를 눌러 보세요.
- **모니터 배율이 달라서(125%/150%) 화분 위치가 어긋나요**: 우클릭 → 크기를 바꿔 보시고 알려 주세요.
- **고친 코드가 반영되지 않아요**: 화분을 우클릭 → 종료한 뒤 `START.bat` 을 다시 실행하세요. 켜져 있는 동안에는 exe 를 새로 만들 수 없어요.

## 초기화
- **갈아엎기**: 지금 화분을 버리고 새 씨앗을 심어요(도감은 그대로). 상태 메모 버튼 또는 우클릭 메뉴.
- **전부 초기화**: 도감까지 모두 지우고 처음부터. 둘 다 4초 안에 한 번 더 눌러야 실행돼요.

## 남은 시간
상태 메모에 "다 클 때까지 약 N시간 M분", "다음 단계까지", "물이 바닥나기까지"가 표시돼요(물이 계속 있다는 가정, 과습이면 2배, 테스트 모드면 배속 반영).

## 놀아주기 · 영양제 · 배속 · 이름 · 꾸미기 (v0.3)
- **놀아주기**: 우클릭 메뉴 「장난감 떨어뜨리기」 또는 **Ctrl+Alt+T**. 공·털실·나비·비눗방울이 커서 위치에서 화면 위로부터 떨어지고, 화분이 쫓아가서 받아쳐요. 받아칠 때마다 애정이 오르고(+4) 물이 있으면 성장이 조금 빨라져요(식물 한 개당 최대 1시간). 비눗방울은 한 번 닿으면 터져요.
- **영양제**: 먹이면 1시간 동안 성장 1.5배. 먹이고 2시간 뒤에 또 줄 수 있어요(과습일 땐 못 줘요). 상태 메모나 우클릭 메뉴에서.
- **성장 속도**: 1배 / 2배 / 3배. 성장만 빨라지고 물은 그대로 마르니까, 자리를 비우는 날엔 물을 넉넉히 주고 켜 두세요. (30배속 「테스트 모드」는 따로 있어요.)
- **이름 짓기**: 상태 메모에서 8글자까지. 말풍선·상태 메모에 나오고, 수확하면 도감 카드에 이름이 남아요.
- **꾸미기 아이템** (옷장 메모, 화분 색과 상관없이 모든 화분에 어울려요): 머리·얼굴·목 3칸, 칸마다 하나씩 착용.
  | 아이템 | 얻는 법 |
  |---|---|
  | 빨간 리본 | 첫 씨앗 수확 |
  | 꽃핀 / 반짝 왕관 | 도감 2종 / 5종 |
  | 동그란 안경 | 처음으로 갈아엎기 |
  | 선글라스 | 과습에서 처음 회복 |
  | 목도리 | 이름 지어주기 |
  | 나비넥타이 | 장난감으로 10번 놀아주기 |
  | 방울 목걸이 | 애정 가득 채우기 |
  | 밀짚모자 | 물 30번 주기 |
  | 베레모 | 5번 수확 |
  | 꽃 화관 | 도감 10종 전부 채우기 |
  | 하트 안경 | 애정 5번 가득 채우기 |
  | 외알 안경 | 레어 식물 수확 |
  | 콧수염 | 영양제 5번 먹이기 |
  | 진주 목걸이 | 희귀 식물 수확 |
  | 꽃 목걸이 | 이름 지어준 식물 수확 |
  | 금메달 | 장난감으로 30번 놀아주기 |
  | 보라돌이 / 뚜비 / 나나 / 뽀 안테나 | 같은 이름의 화분 색으로 수확 |
- 「전부 초기화」는 도감과 아이템까지 지워요. 「갈아엎기」는 도감·아이템을 지키고 화분만 새로 심어요.

# 🌱 화분 펫 (pot-pet)

화분 색은 내가 고르고, 안에서 뭐가 자랄지는 랜덤인 도트 화분을 바탕화면에서 키우는 프로그램이에요.
화분은 모니터 전체를 돌아다니고, 상태와 도감은 숨길 수 있는 스티커 메모 창으로 떠 있어요.

## 실행 방법 (Windows)

1. [Node.js](https://nodejs.org) LTS 버전 설치 (이미 있으면 생략)
2. 폴더 안의 **`START.bat` 을 더블클릭**하면 끝이에요. 처음 한 번만 필요한 설치(1~2분)를 자동으로 하고, 이후에는 바로 화분이 떠요. 콘솔 창은 저절로 닫혀요.

터미널을 쓰고 싶다면 이 폴더에서 PowerShell 을 열고:

```
npm install
npm start
```

처음 `npm install` 은 Electron 을 내려받느라 1~2분 걸려요. 이후에는 `npm start` 만 하면 돼요.

### 「Electron 을 찾지 못했어요」가 뜰 때
회사 네트워크나 보안 프로그램이 Electron 본체(약 100MB)를 내려받는 걸 막을 때 생겨요. START.bat 이 미러 주소로 한 번 더 시도하지만 그래도 안 되면, Electron 이 이미 설치된 PC(START.bat 으로 화분이 뜨는 PC)에서 **`make-portable.bat`** 을 실행하세요. Node.js 없이 `PotPet.exe` 만 눌러도 실행되는 `PotPet-portable.zip` 이 만들어지니, 그 zip 만 동료에게 전달하면 돼요.

## 키우는 방법

- 씨앗에서 다 자랄 때까지 **물 먹은 시간 8시간**(하루)이에요. 물은 한 번에 3시간 버텨요.
- 단계: 씨앗 → 새싹(30분) → 쑥쑥(2시간) → **정체 공개**(4시간) → 수확(8시간).
  새싹일 때는 다 비슷하고, 잎 색만 조금 달라요. 4시간 지나 모양이 잡히면 무슨 식물인지 알려줘요.
- 물이 떨어지면 죽지 않고 **시들어서** 성장만 멈춰요. 고개를 푹 숙이고 눈물이 맺혀요. 물을 주면 살아나요.
- **물을 너무 많이 줘도 시들어요.** 물이 이미 가득할 때(90% 이상) 또 주면 과습이 돼요. 성장이 절반 속도로 느려지고, **다음 성장 단계에 오르면 저절로 회복**해요. 물이 가득할 때 누르면 먼저 "한 번 더 눌러요" 하고 물어보고(4초 안에 다시 누르면 진짜로 줘요), 과습인 동안은 물이 모자라지기(25% 미만) 전까지 더 줄 수 없고, 모자라지면 다시 줄 수 있어요. 물 주기는 상태 메모의 「물 주기」 버튼이나 화분 우클릭 메뉴로 해요.
- 다 자라면 도감에 등록되고, "새 씨앗 심기"로 다음 씨앗을 뽑아요.
- 프로그램을 꺼 둔 동안에도 시간이 흐른 만큼 자라요 (최대 하루치).

### 식물 10종 (도감)

| 희귀도 | 확률 | 종류 |
| --- | --- | --- |
| 일반 | 60% | 방울토마토, 바질, 선인장, 해바라기, 상추, 민트 |
| 희귀 | 30% | 딸기, 라벤더 |
| 레어 | 10% | 보라 바질, 황금 방울토마토 (반짝여요) |

## 조작

| 동작 | 결과 |
| --- | --- |
| 화분을 **누른 채 좌우로 문지르기** | 쓰다듬기. 하트가 나오고 애정이 차요. 애정이 차면 성장이 빨라져요 (식물 한 개당 최대 2시간치) |
| 화분 **Shift + 드래그** (또는 휠 클릭 드래그) | 들어서 옮기기 |
| 화분 **우클릭** | 메뉴 (물 주기, 새 씨앗, 상태/도감 메모, 화분 색, 지내는 방식, 크기, 종료) |
| 상태 메모의 **물 주기** 버튼 | 물 주기 |
| 메모 머리글 드래그 / × | 메모 옮기기 / 숨기기 |
| **Ctrl + Alt + P** | 화분과 메모 전부 숨기기 / 다시 보이기 |
| 트레이 아이콘 우클릭 | 숨기기, "화분 불러오기"(못 찾을 때), 메모 켜기/끄기, 종료 |

### 지내는 방식 (우클릭 → 지내는 방식)

- **화면 전체 돌아다니기** (기본): 모니터 어디든, 모니터가 여러 개면 모니터 사이도 넘나들어요. 가끔 커서를 따라와요.
- **작업표시줄 위 걷기**: 바닥만 걸어요. 들어서 놓으면 바닥으로 떨어져요.
- **커서 따라가기**: 커서를 계속 졸졸 따라와요.
- **가만히 있기**: 제자리에서 가끔 폴짝만 해요.

걸어 다니다가 가끔 **폴짝** 뛰어요. 그리고 **혼잣말**을 해요. "오늘도 홧팅이에요!", "물 한 잔 마셔요~" 같은 응원과 귀여운 말, 시간대별 말이 나와요. 우클릭 → **말 걸기**에서 자주(1~2분) / 가끔(2~4분, 기본) / 조용히로 바꿀 수 있어요. 문구는 `renderer/game.js` 맨 위의 `TALK_` 목록에서 마음대로 고칠 수 있어요.

그 밖에: 화분 말고 투명한 부분은 클릭이 뒤쪽 창으로 그대로 통과해요. 키보드와 마우스 입력이 5분 없으면 낮잠을 자요(zzz). 아침, 점심, 퇴근 시간에 인사해요.

## 아직 안 들어간 것

- **창 위에 앉기 / 창 뒤에 짱박기**: 체험판에서 보여드린 가짜 창이 아니라 실제 창 위치를 알아야 해서, 이 버전에는 없어요. (다음 단계에서 추가 가능)
- 찾아오는 손님(나비 등)

## exe 로 묶기 (선택)

```
npm i -D electron-builder
npx electron-builder --win portable
```

`dist/` 에 설치 없이 실행되는 exe 가 만들어져요. 윈도우 시작 시 자동 실행은 `START.bat` 의 바로가기(또는 만들어진 exe)를 `Win + R` → `shell:startup` 폴더에 넣으면 돼요.

## 글꼴

한글 도트 폰트 **갈무리(Galmuri)** 를 `renderer/fonts/` 에 함께 넣어 두었어요 (SIL OFL 1.1, 라이선스 파일 포함). 인터넷 없이도 나와요.

## 저장 위치

`%APPDATA%\pot-pet\` 안의 `potpet-save.json` (게임), `potpet-ui.json` (메모 창 위치). 지우면 처음부터 다시 시작해요.

## 문제 해결

- **화분이 안 보여요**: 트레이 아이콘 우클릭 → "화분 불러오기", 또는 Ctrl+Alt+P 를 눌러 보세요.
- **모니터 배율이 달라서(125%/150%) 화분 위치가 어긋나요**: 우클릭 → 크기를 바꿔 보시고 알려 주세요.
- **개발자 도구로 보고 싶어요**: PowerShell 에서 `$env:POTPET_DEBUG=1; npm start`

## 초기화
- **갈아엎기**: 지금 화분을 버리고 새 씨앗을 심어요(도감은 그대로). 상태 메모 버튼 또는 우클릭 메뉴.
- **전부 초기화**: 도감까지 모두 지우고 처음부터. 둘 다 4초 안에 한 번 더 눌러야 실행돼요.

## 남은 시간
상태 메모에 "다 클 때까지 약 N시간 M분", "다음 단계까지", "물이 바닥나기까지"가 표시돼요(물이 계속 있다는 가정, 과습이면 2배, 테스트 모드면 배속 반영).

## 놀아주기 · 영양제 · 배속 · 이름 · 꾸미기 (v0.3)
- **놀아주기**: 우클릭 메뉴 「장난감 떨어뜨리기」 또는 **Ctrl+Alt+T**. 공·털실·나비·비눗방울이 커서 위치에서 화면 위로부터 떨어지고, 화분이 쫓아가서 받아쳐요. 받아칠 때마다 애정이 오르고(+4) 물이 있으면 성장이 조금 빨라져요(식물 한 개당 최대 1시간). 비눗방울은 한 번 닿으면 터져요.
- **영양제**: 먹이면 1시간 동안 성장 1.5배. 먹이고 2시간 뒤에 또 줄 수 있어요(과습일 땐 못 줘요). 상태 메모나 우클릭 메뉴에서.
- **성장 속도**: 1배 / 2배 / 3배. 성장만 빨라지고 물은 그대로 마르니까, 자리를 비우는 날엔 물을 넉넉히 주고 켜 두세요. (30배속 「테스트 모드」는 따로 있어요.)
- **이름 짓기**: 상태 메모에서 8글자까지. 말풍선·상태 메모에 나오고, 수확하면 도감 카드에 이름이 남아요.
- **꾸미기 아이템** (옷장 메모, 화분 색과 상관없이 모든 화분에 어울려요): 머리·얼굴·목 3칸, 칸마다 하나씩 착용.
  | 아이템 | 얻는 법 |
  |---|---|
  | 빨간 리본 | 첫 씨앗 수확 |
  | 꽃핀 / 반짝 왕관 | 도감 2종 / 5종 |
  | 동그란 안경 | 처음으로 갈아엎기 |
  | 선글라스 | 과습에서 처음 회복 |
  | 목도리 | 이름 지어주기 |
  | 나비넥타이 | 장난감으로 10번 놀아주기 |
  | 방울 목걸이 | 애정 가득 채우기 |
- 「전부 초기화」는 도감과 아이템까지 지워요. 「갈아엎기」는 도감·아이템을 지키고 화분만 새로 심어요.

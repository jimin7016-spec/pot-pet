화분 펫 (설치 필요 없는 버전)

1. 압축을 다 푼 폴더 안에서 PotPet.exe 를 더블클릭하세요. (Node.js, npm 설치가 필요 없어요)
2. Windows 가 "PC 보호" 파란 창을 띄우면 [추가 정보] → [실행] 을 눌러 주세요. (서명되지 않은 프로그램이라 처음 한 번만 나와요)
3. 종료는 화분 우클릭 → 종료, 또는 작업표시줄 오른쪽 트레이 아이콘 → 종료.
4. 화분이 안 보이면 트레이 아이콘 → "화분 불러오기".

- 반드시 압축을 "모두 풀기" 한 뒤 실행해 주세요. (압축 파일 안에서 바로 열면 안 돼요)
- 저장 파일: %APPDATA%\pot-pet\potpet-save.json
- 단축키: Ctrl+Alt+P 화분 숨기기/보이기, Ctrl+Alt+T 장난감 떨어뜨리기
